# Pistol Aiming Mod (PAM)

## Description:
This mod adds the ability to aim with all 6 of the pistols available in the game. Aiming was not added to the flare gun.
The zoom factor has been calibrated at 1.1x (changed from 1.0x). 
All pistols have had their aimed accuracy improved, though they remain the least accurate weapons in the game.

This mod is NOT COMPATIBLE with any mod that adds new items or edits item attributes via items.sav or changes animations via FpvAnims.sav. The mod is only required on the game client, not the server.

PAM uses the first person pistol models from ShayoX's enhanced weapon models, but his entire mod is highly recommended: https://www.nexusmods.com/hiddenanddangerous2courageunderfire/mods/2

## Installation:
- Choose either the default version, or the version which includes the =RpR= clan uniform as an additional item
- Copy the Models and Tables folders into your game folder.
